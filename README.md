# Statek Cholupice

Repozitář obsahuje schválený statický návrh a release candidate WordPress šablony s companion pluginem.

## Testovat ve WordPress Playgroundu

WordPress Playground spustí dočasný WordPress přímo v prohlížeči, nainstaluje šablonu i companion plugin z pracovní větve a otevře administraci přihlášenou jako správce.

**[Spustit Statek Cholupice ve WordPress Playgroundu](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2FMonkeycons%2Fstatek-cholupice-navrh%2Frefs%2Fheads%2Ffeat%2Fwordpress-production-theme%2Fplayground%2Fblueprint.json)**

Praktický postup kontroly je v dokumentu [playground/TESTING.md](playground/TESTING.md).

Změny provedené v dočasné instanci Playgroundu nejsou trvalé. Playground rovněž neověřuje skutečné doručení e-mailů přes konfiguraci cílového hostingu.
Aktualni WordPress balicky: sablona `1.1.0-rc.4`, companion plugin `1.1.0-rc.3`.
